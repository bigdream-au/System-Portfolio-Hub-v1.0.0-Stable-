# 📊 System Diagnostics Portfolio Hub

A compiled, production-ready Windows desktop utility designed to showcase native operating system integration, clean software architecture, and standalone tool distribution. 🛠️

---

## 📥 Deployment & Installation
The compiled application is distributed as a zero-installation, portable executable binary. 📦

To run the standalone desktop application, navigate to the **Releases** section on the right side of this repository page and download the latest executable file asset. Once downloaded, double-click the file to launch the live system diagnostics dashboard instantly on Windows. 🚀

---

## 🎯 Engineering Objectives
Unlike traditional static portfolios, this project acts as a functional system-level application. It interfaces directly with native operating system modules to track computer metrics, serving as a live technical demonstration for scholarship boards and software engineering recruiters. 🖥️

## ⚙️ Core Technical Features
* **⚡ Native OS Diagnostics:** Queries system-level runtime variables to display real-time computer specifications and live uptime metrics.
* **📦 Portable Architecture:** Wrapped securely using the builder framework to compile all source logic, styles, and engines into one single, downloadable executable binary.
* **🛡️ Zero Dependency Footprint:** Requires no local installation of frameworks, runtimes, or command-line configurations by the reviewer—runs seamlessly on double-click.

## 🛠️ Technology Stack
* **⚙️ Runtime Environment:** Node.js & Electron Framework
* **🎨 User Interface:** HTML5, JavaScript, Tailwind CSS
* **🏗️ Compiler Framework:** Build Target Configuration (Portable Win-x64)

## 📐 Architecture Overview
The application separates system processing from the presentation layer. The background controller handles system-level API queries and state metrics, while the frontend dashboard manages responsive data updates and user interface rendering. 🔄
